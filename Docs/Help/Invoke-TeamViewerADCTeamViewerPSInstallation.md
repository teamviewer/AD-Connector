# Invoke-TeamViewerADCTeamViewerPSInstallation

## SYNOPSIS

Installs the TeamViewerPS module dependency.

## SYNTAX

```powershell
Invoke-TeamViewerADCTeamViewerPSInstallation [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Ensures that the TeamViewerPS module, used for all TeamViewer web API calls, is installed for all users.
If the module is already present, no action is taken. Returns `$true` when the module is available after the call, otherwise `$false`.

Installing for all users requires administrator privileges.

## EXAMPLES

### Example 1

```powershell
PS C:\> Invoke-TeamViewerADCTeamViewerPSInstallation
```

Installs the TeamViewerPS module for all users if it is not already installed.
