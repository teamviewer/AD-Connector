# Remove-TeamViewerADCScheduledTask

## SYNOPSIS

Removes the automatic synchronization scheduled task.

## SYNTAX

```powershell
Remove-TeamViewerADCScheduledTask [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Unregisters the 'Automatic Synchronization' scheduled task created by New-TeamViewerADCScheduledTask.
If the task does not exist, no action is taken.

Requires administrator privileges.

## EXAMPLES

### Example 1

```powershell
PS C:\> Remove-TeamViewerADCScheduledTask
```

Removes the automatic synchronization scheduled task if it exists.
