# Invoke-TeamViewerADCConfiguration

## SYNOPSIS

Opens the graphical configuration interface of the TeamViewer AD Connector.

## SYNTAX

```powershell
Invoke-TeamViewerADCConfiguration [[-Config_File] <String>] [[-Culture] <String>] [-ProgressAction <ActionPreference>]  [<CommonParameters>]
```

## DESCRIPTION

Loads the specified configuration file and opens a graphical interface to review and change the settings, validate the TeamViewer API token, trigger a manual synchronization run, and install or remove the scheduled synchronization task.

This command requires administrator privileges because it manages the scheduled task.
Start PowerShell as administrator before running it.

## EXAMPLES

### Example 1

```powershell
PS C:\> Invoke-TeamViewerADCConfiguration
```

Opens the configuration interface using the default configuration file and the current system language.

### Example 2

```powershell
PS C:\> Invoke-TeamViewerADCConfiguration -Config_File 'C:\ProgramData\TeamViewerADC\TeamViewerADC.json' -Culture 'de'
```

Opens the configuration interface for a specific configuration file, using German localization.
