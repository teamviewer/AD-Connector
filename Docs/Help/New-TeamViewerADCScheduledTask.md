# New-TeamViewerADCScheduledTask

## SYNOPSIS

Creates the scheduled task that runs the synchronization automatically.

## SYNTAX

```powershell
New-TeamViewerADCScheduledTask [[-Interval] <Int32>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Registers a Windows scheduled task named 'Automatic Synchronization' under the '\TeamViewerADC\' task path.
It runs Invoke-TeamViewerADCSynchronization on a recurring interval as the NETWORK SERVICE account.
If the task already exists, the existing task is returned and no new task is created.

Requires administrator privileges.

## EXAMPLES

### Example 1

```powershell
PS C:\> New-TeamViewerADCScheduledTask -Interval 12
```

Creates a scheduled task that runs the synchronization every 12 hours.
