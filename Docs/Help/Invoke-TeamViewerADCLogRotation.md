# Invoke-TeamViewerADCLogRotation

## SYNOPSIS

Removes old TeamViewer AD Connector log files.

## SYNTAX

```powershell
Invoke-TeamViewerADCLogRotation [[-Directory] <String>] [[-Basename] <String>] [[-Retention] <Int32>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Deletes the oldest synchronization log files in the given directory so that only the configured number of most recent files is kept.

## EXAMPLES

### Example 1

```powershell
PS C:\> Invoke-TeamViewerADCLogRotation -Directory 'C:\ProgramData\TeamViewerADC\Logs' -Retention 30
```

Keeps the 30 most recent `TeamViewerADC*.log` files in the given directory and deletes the rest.
