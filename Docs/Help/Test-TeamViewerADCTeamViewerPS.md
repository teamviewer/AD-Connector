# Test-TeamViewerADCTeamViewerPS

## SYNOPSIS

Tests whether the TeamViewerPS module is installed.

## SYNTAX

```powershell
Test-TeamViewerADCTeamViewerPS [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Checks whether the TeamViewerPS module, required for the TeamViewer web API calls, is installed.
Returns `$true` if the module is installed, otherwise `$false`.

## EXAMPLES

### Example 1

```powershell
PS C:\> Test-TeamViewerADCTeamViewerPS
```

Returns whether the TeamViewerPS module is currently installed.
